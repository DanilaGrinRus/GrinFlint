# node-spike

Экспериментальный крейт, **не входящий в приложение**. Отвечает на вопрос:
собираются ли node-библиотеки Grin (`grin_servers`, `grin_config`, `grin_p2p`,
`grin_api`) как staticlib под iOS-симулятор.

Запуск — workflow `Node Spike` (вручную). Он же измеряет на macOS:

- время первичного синка ноды из снапшота floonet (`floonet-chain-2026-10-28`);
- пиковый RSS процесса ноды;
- размер каталога цепи;
- время «подкачки» после рестарта (сколько нужно при следующем запуске).

Ограничения спайка: измерения идут на macOS-раннере, а не на iPhone — тепловой
троттлинг, батарея и фон iOS здесь не измеряются. Запуск ноды в симуляторе и
менеджер ноды — следующий шаг после результатов этого workflow.
